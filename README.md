# Sides

A teleprompter and memorization tool for actors' audition sides. Runs in the browser, no account needed.

- Teleprompter and Memorize modes
- Loop a chunk: repeat a few lines until you know them
- Self-tape with the script beside the camera
- Look up a word: meanings and how to say it

Open the live page from the Pages link in this repo's settings. Works best in Chrome, Edge or Brave.
